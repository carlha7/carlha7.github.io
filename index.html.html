Caso de estudio: Alke Wallet

El proyecto que mejor refleja mi crecimiento tecnico. Lo elegi porque reune casi todo lo que aprendi en el curso dentro de una sola aplicacion web funcional.

De que se trata

Alke Wallet es una billetera digital desarrollada con Django. Permite registrar clientes, crear sus cuentas y registrar transacciones entre usuarios, todo con una base de datos que mantiene la informacion ordenada y segura.

El desafio principal

Pasar de escribir scripts sueltos a construir una aplicacion web completa. Tenia que lograr que los modelos, las relaciones entre tablas, las migraciones y las vistas trabajaran juntos sin romperse, y ademas cuidar la seguridad de los formularios.

La solucion que propuse

Modele los datos con tres entidades relacionadas (Cliente, Cuenta y Transaccion) usando el ORM de Django, apliqué migraciones para reflejar esos modelos en la base de datos, y arme vistas CRUD para crear, ver, editar y eliminar registros. Sume el panel de administracion, el sistema de login y consultas personalizadas para obtener informacion especifica.

Herramientas que use

Python y Django como base, SQLite para el desarrollo (con PostgreSQL previsto para produccion), el ORM y las migraciones de Django, el panel de administracion, Git y GitHub para el control de versiones, y Visual Studio Code como editor.

Lo que aprendi

Entendi como piensa un framework web: separar los datos, la logica y las vistas. Aprendi a confiar en las migraciones para no perder informacion, a proteger los formularios contra ataques y a apoyarme en las herramientas que Django ya trae en lugar de reinventar todo.

Impacto medible

La aplicacion pasa sus 12 pruebas automatizadas y el comando de verificacion de Django no reporta problemas. El uso del panel de administracion me ahorro tener que programar pantallas de gestion desde cero, y las migraciones dejaron un historial ordenado de cada cambio en la base de datos.

Habilidades tecnicas aplicadas

Modelado de datos con ORM, relaciones entre tablas, migraciones, operaciones CRUD, consultas con filtros y SQL, seguridad de formularios (CSRF), autenticacion de usuarios, pruebas unitarias y control de versiones con Git.

Por que elegi este proyecto

Porque marca el momento en que dejo de resolver ejercicios aislados y logro construir algo parecido a un producto real. Ademas conecta con mi experiencia previa analizando procesos y sistemas comerciales: ahora puedo aportar tambien desde el lado del desarrollo.
